# Code of Conduct

## Our standard

We want participation in NutriScan to be welcoming, respectful, and constructive. Treat others with patience, assume good faith, and focus criticism on ideas and work rather than people.

Unacceptable behavior includes harassment, discrimination, personal attacks, intimidation, and sharing another person's private information without permission.

## Maintainer response

Project maintainers may edit or remove contributions that violate this code and may restrict participation when needed to keep the project safe and constructive.

## Reporting

Report conduct concerns privately to the repository maintainer through the contact method listed on the [Devil-54 GitHub profile](https://github.com/Devil-54). Please include enough context to understand and address the issue. Reports will be handled as confidentially as practical.
